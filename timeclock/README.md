# คู่มือติดตั้งระบบลงเวลานอกสถานที่ + OT

ระบบมี 2 ไฟล์
- `index.html` คือหน้าเว็บที่พนักงานเปิดบนมือถือ
- `Code.gs` คือระบบหลังบ้านที่บันทึกลง Google Sheets และเก็บรูปไว้ใน Google Drive

## 1. ตั้งค่าหลังบ้าน (ประมาณ 5 นาที ทำครั้งเดียว)
1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น "ลงเวลาพนักงาน Baiyoke-Queensland"
2. ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script** ลบโค้ดเดิมทิ้ง แล้ววางโค้ดจาก `Code.gs` จากนั้นกดบันทึก 💾
3. ที่แถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **Run** ระบบจะขออนุญาตใช้งาน Sheets และ Drive ให้กดอนุญาต (ถ้าขึ้นว่า "Google hasn't verified this app" ให้กด Advanced → Go to …)
   ระบบจะสร้างชีต Employees, Attendance, OT และ Hotels ให้อัตโนมัติ
4. กด **Deploy → New deployment** เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอก **Web app URL** ซึ่งลงท้ายด้วย `/exec`

## 2. เชื่อมหน้าเว็บ
แก้ไฟล์ `config.js` ใน GitHub (repo f-b-Manpower → โฟลเดอร์ timeclock → config.js → ปุ่มดินสอ) แล้ววาง URL ลงไป
```
window.TC_SCRIPT_URL = 'https://script.google.com/macros/s/xxxx/exec';
```
กด Commit แล้วรอ 1–2 นาที พนักงานทุกคนจะบันทึกลงชีตเดียวกันทันที ไม่ต้องแก้ไฟล์อื่น

- ใช้ลิงก์เดียว `…/timeclock/` ทั้งพนักงานและแอดมิน

> ต้องเปิดผ่าน https ด้วย Chrome หรือ Safari ถ้าเปิดในแอป LINE หรือ Facebook การสแกนนิ้วและ GPS อาจใช้ไม่ได้
> ถ้าแก้ `Code.gs` ภายหลัง ต้องกด Deploy → Manage deployments → ✏️ → Version: New version ทุกครั้ง ระบบถึงจะใช้โค้ดใหม่

## แท็บ "รายงาน" (เฉพาะแอดมิน)
- **ผู้ดูแลระบบ:** ชัชวาลย์ ต่อสุวรรณ
- **วิธีเข้า:** ไปที่ **ตั้งค่า → เข้าสู่ระบบแอดมิน** (หรือกดลิงก์ใต้ฟอร์มลงทะเบียน) แล้วใส่รหัสผ่าน แท็บ "รายงาน" และเมนูวัดพิกัดจะขึ้นมา ใช้ได้จากทุกเครื่อง ไม่ต้องผูกลายนิ้วมือ และระบบจะออกจากแอดมินให้อัตโนมัติเมื่อปิดเบราว์เซอร์
- **ความปลอดภัย:** ในโค้ดมีแค่ค่า hash ของรหัสผ่าน ไม่มีรหัสจริง ถ้าใส่รหัสผิด 5 ครั้ง ระบบจะล็อก 15 นาที
- **เปลี่ยนรหัสผ่าน:** หลังเชื่อม Google Sheets แล้ว ให้ใส่รหัสใหม่ที่ชีต **Admin** ช่อง B3 (ชีตนี้เห็นได้เฉพาะเจ้าของ) ถ้าเว้นว่างไว้ ระบบจะใช้รหัสเริ่มต้น
- **กระดานรายวัน:** ใครเข้า-ออกกี่โมง อยู่โรงแรมไหน ใครยังไม่สแกนออก พร้อมลิงก์แผนที่และรูปหลักฐาน
- **สรุปรายคน:** วันทำงาน จำนวนครั้งที่ลืมสแกนออก และชั่วโมงกับเงิน OT ทั้งที่อนุมัติแล้วและที่รออนุมัติ
- **อนุมัติ OT:** กดอนุมัติหรือไม่อนุมัติได้ทันที ระบบจะบันทึกลงชีต OT ให้
- **พนักงาน:** รายชื่อพนักงาน สิทธิ์ และสถานะการผูกเครื่อง
- กรองตามเดือน โรงแรม หรือชื่อพนักงาน แล้วกด **ส่งออก Excel** จะได้ไฟล์ .xlsx ที่มีโลโก้ Queensland อยู่หัวกระดาษ แบ่งเป็น 3 แผ่นงาน คือ สรุปรายคน, OT และบันทึกสแกน มีแถวรวมยอด และตั้งค่าหน้ากระดาษ A4 แนวนอนพร้อมพิมพ์
- **ใช้งานพร้อมกันได้:** หลังบ้านมีระบบคิว (LockService) ป้องกันข้อมูลชนกัน

## 3. งานของ HR ในชีต
- **Employees**: พนักงานจะถูกเพิ่มอัตโนมัติเมื่อลงทะเบียนครั้งแรก ใส่เวลาเข้างานและเลิกงานได้ (ไม่ต้องใส่เงินเดือน เพราะ OT ใช้อัตราตายตัว 60 บาท/ชม.)
- **Attendance**: ทุกครั้งที่สแกนเข้าหรือออก จะบันทึกเวลาของเซิร์ฟเวอร์ (พนักงานแก้เวลาในเครื่องเพื่อโกงไม่ได้) พิกัด GPS พร้อมค่าความแม่นยำ ลิงก์แผนที่ และลิงก์รูปเซลฟี่ ซึ่งบนรูปจะประทับเวลาและพิกัดไว้
- **OT**: ระบบสร้างให้อัตโนมัติจากเวลาสแกน แอดมินอนุมัติได้ในแท็บรายงาน หรือแก้คอลัมน์ "สถานะ" ในชีตเป็น "อนุมัติ" หรือ "ไม่อนุมัติ"
- **พนักงานเปลี่ยนมือถือ**: ให้ลบช่อง `credentialId` ของพนักงานคนนั้น แล้วให้เขาลงทะเบียนใหม่บนเครื่องใหม่

## เวลาทำงานและ OT (ไม่มีกะตายตัว)
- **เวลาเริ่มงาน:** เป็นชั่วโมงตรงเท่านั้น ระบบปัดเวลาสแกนเข้าเป็นชั่วโมงที่ใกล้ที่สุด
  - สแกน 06:50 หรือ 07:20 → นับเริ่ม **07:00** → เลิกงานปกติ **16:00**
  - สแกน 07:30 หรือ 07:40 → นับเริ่ม **08:00** → เลิกงานปกติ **17:00**
- **ทำงานปกติ 9 ชม.:** นับจากเวลาเริ่ม (ทำงาน 8 ชม. + พัก 1 ชม.)
- **OT:** ถ้าสแกนออกหลังเวลาเลิกงานปกติ ส่วนที่เกินคือ OT ระบบคำนวณให้อัตโนมัติตอนสแกนออก **นับเฉพาะชั่วโมงเต็ม ไม่คิดเศษนาที** ชั่วโมงละ 60 บาท
  - เริ่ม 07:00 สแกนออก 16:45 → เกิน 45 นาที → ไม่มี OT
  - เริ่ม 07:00 สแกนออก 17:50 → เกิน 1 ชม. 50 นาที → OT 1 ชม. = 60 บาท
  - เริ่ม 07:00 สแกนออก 18:05 → เกิน 2 ชม. 5 นาที → OT 2 ชม. = 120 บาท
- **พนักงานยื่น OT เองไม่ได้:** OT มาจากเวลาสแกนจริงเท่านั้น พนักงานใส่ได้แค่ "งานที่ทำ/เหตุผล" ระหว่างที่ OT ยังรออนุมัติ
- **ต้องให้แอดมินอนุมัติ:** OT ทุกรายการเริ่มที่สถานะ "รออนุมัติ" ยอดที่สรุปจ่ายนับเฉพาะรายการที่อนุมัติแล้ว
- **งานข้ามคืน:** ระบบจับคู่สแกนออกกับสแกนเข้าล่าสุดภายใน 24 ชม. เช่น เข้า 22:45 (นับเริ่ม 23:00) ออก 09:10 → OT 1 ชม.
- **สแกนออกซ้ำ:** ระบบอัปเดตรายการ OT เดิมของกะนั้น ไม่สร้างรายการใหม่ซ้ำ
- **เปลี่ยนจำนวนชั่วโมง:** แก้ `WORK_MIN` ทั้งใน `Code.gs` และ `index.html` ถ้าจะเปลี่ยนอัตรา OT แก้ `OT_RATE`

## โรงแรมและการตรวจพื้นที่ (บล็อกการสแกนนอกพื้นที่)
- สถานที่ที่กำหนดไว้มี 2 แห่ง คือ **Baiyoke Sky Hotel Bangkok** และ **Queensland Hotel Bangkok**
- จะสแกนได้ก็ต่อเมื่อ (1) อยู่ห่างจุดสแกนไม่เกิน**รัศมี** (ค่าเริ่มต้น **50 ม.**) และ (2) GPS แม่นยำไม่เกิน **±65 ม.** (เผื่อสัญญาณในตึกสูง) ถ้าไม่ผ่านจะกดบันทึกไม่ได้ ระบบหลังบ้านตรวจซ้ำอีกชั้นด้วย จึงแก้หน้าเว็บเพื่อข้ามการตรวจไม่ได้
- ระบบเก็บค่า GPS หลายครั้งแล้วใช้ค่าที่แม่นที่สุด และเลือกโรงแรมที่อยู่ใกล้ที่สุดให้อัตโนมัติ

### ขั้นตอนสำคัญ: HR ต้องวัดพิกัดจริงที่หน้างาน (ทำครั้งเดียว)
พิกัดเริ่มต้นได้มาจากเว็บไซต์ แต่ละเว็บให้ค่าของควีนส์แลนด์ไม่ตรงกัน (ต่างกันประมาณ 300 ม.) จึงต้องวัดจริงที่หน้างาน
1. ไปยืนตรงจุดที่ให้พนักงานสแกน เช่น ประตูพนักงาน หรือจุดที่เคยมีเครื่องสแกนนิ้ว
2. เปิดเว็บ ไปที่ **ตั้งค่า → วัดพิกัดจุดสแกน** เลือกโรงแรม แล้วกด **เริ่มวัดพิกัด** รอประมาณ 30 วินาที
3. นำตัวเลข lat, lng ที่ได้ไปใส่ในชีต **Hotels** (ชีตนี้สร้างเองอัตโนมัติ) ทำซ้ำกับอีกโรงแรม
4. ปรับรัศมีในชีตได้เลย ตึกสูงอย่างใบหยก GPS ในอาคารจะคลาดเคลื่อนมาก รัศมี 50 ม. ต้องใช้พิกัดที่วัดจริงเท่านั้น และควรเลือกจุดสแกนที่รับสัญญาณ GPS ได้ดี เช่น ประตูหรือใกล้หน้าต่าง ถ้าพนักงานสแกนไม่ผ่านบ่อย ให้ปรับรัศมีหรือค่าความแม่นยำในชีต Hotels

## ข้อควรรู้
- ข้อมูลลายนิ้วมือ**ไม่ได้ถูกส่งออกจากมือถือ** มือถือใช้ลายนิ้วมือหรือ Face ID ยืนยันตัวผู้ใช้ภายในเครื่อง แล้วส่งรหัสอุปกรณ์ที่ผูกไว้ให้ระบบ ระบบจึงยืนยันได้ว่า "เจ้าของเครื่องที่ลงทะเบียนไว้เป็นคนสแกน"
- ระบบเวอร์ชันนี้ตรวจรหัสอุปกรณ์ แต่ยังไม่ได้ตรวจลายเซ็นดิจิทัลแบบเต็มรูปแบบที่หลังบ้าน ถือว่าเพียงพอสำหรับงานทั่วไป ถ้าต้องการความปลอดภัยระดับสูงกว่านี้ ควรเพิ่มการตรวจลายเซ็น WebAuthn ฝั่งเซิร์ฟเวอร์
- GPS บนมือถือคลาดเคลื่อนได้ประมาณ 5–50 ม. แยกชั้นของอาคารไม่ได้ และอาจถูกปลอมด้วยแอป Fake GPS ระบบจึงเก็บรูปที่ถ่ายจากกล้องไว้เป็นหลักฐานประกอบ ถ้าต้องการให้แน่นอน 100% แนะนำให้เพิ่มการสแกน QR ที่เปลี่ยนรหัสทุก 30 วินาที โดยแสดงจากแท็บเล็ตที่ติดไว้หน้าจุดสแกน
- ถ้ายังไม่ได้ใส่ `SCRIPT_URL` ระบบจะทำงานใน "โหมดทดลอง" และเก็บข้อมูลไว้ในเครื่องเท่านั้น เหมาะสำหรับลองใช้งานก่อน
